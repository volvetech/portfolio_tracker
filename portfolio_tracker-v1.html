🚀 一键更新持仓价格（双数据源）

数据源1：东方财富（支持跨域）→ 数据源2：腾讯（脚本加载，免疫CORS）。任一可用即自动完成； 抓取价格的同时会同步保存股票名称并在持仓表中显示。 

点击「数据源自检」可先验证数据源是否可用。
代码识别规则：
• 6位数字，首位 6/9 → 沪市；首位 0/2/3 → 深市；首位 4/8 或 920 开头 → 北交所
• 5位（或4位自动补0）以 0 开头 → 港股通
• 也可带前缀：SH600519 / SZ000001 / HK00700
常见问题：价格为 0 或无数据 = 该代码不被行情接口支持（如特殊基金/期权）或已停牌，请手动填写；港股价格单位为港元。
